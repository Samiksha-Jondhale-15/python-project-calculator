# python-project-calculator
🧮 Simple Calculator in Python  This is a basic command-line calculator implemented in Python. 
It allows users to perform four arithmetic operations:  Addition  Subtraction  Multiplication 
Division (with division-by-zero check) 
🚀 How It Works:
1.The user is prompted to select an operation (1–4).
2.The program takes two numerical inputs.
3.Based on the selected operation, the corresponding function is called.
4.The result is printed on the screen.
5.Division by zero is handled gracefully with an error message.
